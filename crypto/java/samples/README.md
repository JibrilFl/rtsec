# Java примеры работы с PKCS#11 и rtpki

## Введение

В данном проекте приведены примеры взаимодействия с Рутокен из продуктов, написанных на языке Java. Работоспособность
примеров гарантируется с комплектом разработчика Java SE Development Kit 8 (x86).

В примерах для работы с PKCS#11 из Java используется
библиотека [pkcs11jna](https://github.com/AktivCo/pkcs11jna), однако существует более высокоуровневая и удобная
библиотека [pkcs11wrapper](https://github.com/AktivCo/pkcs11wrapper).

В примерах для работы с rtpki из Java используется библиотека
[ru.rutoken.rtpki:rtpki-jvm](https://central.sonatype.com/artifact/ru.rutoken.rtpki/rtpki-jvm).

## Сборка проекта

Для задания пути к rtpkcs11ecp через sunJCA редактируйте конфигурационный файл в папке "cfg".
